# nvcodec: Add a transform for custom CUDA kernels

## Summary

Adds a programmable CUDA transform for progressive NV12 buffers and a bundled tiled Lanczos preset. The preset now handles all eight fixed video orientations while keeping intermediate pixels in shared memory.

## Key decisions

- Apply orientation during the final output write, preserving interleaved U/V ordering without a full-frame temporary image.
- Swap resize axes and pixel aspect ratio for quarter-turns and diagonal flips. Downstream caps describe the oriented output.
- Restrict video-direction to fixed orientations and the Lanczos preset; preserve the external custom-kernel ABI.
- Skip the Lanczos tests when the optional NVRTC library is unavailable; keep external-module support available.
- Reject unsupported orientation/custom combinations and dynamic shared-memory requests above 48 KiB at startup with a settings error. Do not cache failed Lanczos compilations.

## Verification

- Built and loaded nvcodec and compiled the test driver with -Wall -Wextra -Werror.
- All five tests pass: eight orientations, default geometry/PAR, independent double-precision numeric oracle (<=1 pixel code), 64x1080 -> 64x8 chunked processing, READY direction changes and invalid settings.
- With NVRTC hidden from library discovery, the factory remains available, Lanczos tests explicitly skip and the settings-error test passes.
- CUDA memcheck, racecheck and synccheck report zero errors/hazards on the expanded suite.
- Reran PTX/cubin/fatbin loading, native/down/upscale byte checks, READY module/parameter replacement, expected error cases and NVDEC -> rotated CUDA resize -> NVENC. Verified tested source hashes.
